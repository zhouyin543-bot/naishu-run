## 游戏特色与玩法

- **操作方式**
  - **手机/平板触屏**：左右滑动换道 · 上滑跳跃 · 下滑滑铲 · 双击屏幕启用随身滑板
  - **电脑键盘/鼠标**：`← / →`（`A / D`）换道 · `↑ / W / 空格` 跳跃 · `↓ / S` 滑铲 · `E / Shift`（或双击画面）启用随身滑板 · `P / Esc` 暂停
- **双地图 · 7 大动态切换场景**
  - **阳光操场**：红跑道看台 → 教学楼室内走廊 → 漫天落樱的樱花大道（鲜奶专列）
  - **埃及金字塔**：沙漠大道 → 金字塔内部星空墓道 → 尼罗河畔木栈道 → 神庙狮身人面像大道（法老专列）
- **随身滑板限带 1 块 + 跑道随捡随用**
  - 补给站可购买随身滑板，**每局最多携带 1 块**入场双击启用；其余滑板均在地图跑道中随机刷新、随捡随用。
- **3D 奶鼠衣柜（原味 + 11 款创意 3D 皮肤）**
  - 原味奶鼠、黄金小皇冠、红白小围巾、竹蜻蜓潮帽（动态旋转螺旋桨）、樱花花环、甜品小厨师、飞行护目镜、酷盖墨镜（配奶酪大金链）、星月女巫帽、勤劳小蜜蜂、小恶魔装、埃及小法老。
- **单文件零外网依赖**
  - `index.html` 已内联 `three.js r149` 与子集化中英文字体，无需外网 CDN，手机与电脑浏览器点开即玩。
